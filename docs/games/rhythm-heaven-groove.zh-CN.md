# 节奏天国 奇迹之星

[English](rhythm-heaven-groove.md) | **简体中文**

![节奏天国 奇迹之星 iPhone 画面](../assets/rhythm-heaven-level-stage.jpg)

**所需游戏文件**：v0 基础 NSP。不需要更新包。

## 为节奏游戏定制的触摸操作

- 👉 **右半屏是 A**：点击屏幕右半边任意位置。手指位置的光晕显示每次按下。
- 👈 **左半屏随关卡变化**：变为关卡需要的按键，例如 ▼、◀、▶ 或 B。需要多个方向的关卡改为显示小型玻璃十字键。
- 🫧 **更少的屏幕按键**：B、−、+ 始终可用。Y 和 X 只在使用它们的关卡中显示。按键更少遮挡画面。
- ✌️ **多指输入**：可以同时按下左右两半屏。很短的点击也算作完整按下。
- 🪄 **BeatSpell**：左半屏是踏步（B），右半屏是攻击（A），同时显示十字键、X 和 Y。
- 🥁 **Drum Lessons**：完整虚拟手柄，包括十字键、A、B、X、Y、ZR、− 和 +。
- 🐰 **节奏玩具**：在 Who's Got Rhythm? 和音板中，点击选中项目，再点一次确认。

## 用触摸操作菜单

- 📋 **直接点击菜单**：点击菜单项、列表和暂停菜单。长列表中每一行可见项目都可以点击。
- 🗺️ **关卡地图**：左右拖动地图。点击关卡选中，再点一次开始。

## 画面、声音与性能

- ✨ **环境光黑边**：黑边实时发出与画面边缘颜色相同的光。
- 🔍 **1080p 渲染**：游戏以 1920×1080 渲染。
- 📱 **iPad 布局**：在 iPad 上，B、Y、X、−、+ 移到画面上方的黑边中。
- 📺 **根据音频输出切换 TV 或掌机模式**：蓝牙、AirPlay 和 HDMI 音频会切换到 TV 模式，并提供延迟校准。内置扬声器和有线耳机使用掌机模式。
- ⚡ **更流畅的 BeatSpell**：战斗场景跳过不必要的 GPU 等待。在 Mac 测试中，每帧工作时间从约 14.6 毫秒降到约 9.5 毫秒。
